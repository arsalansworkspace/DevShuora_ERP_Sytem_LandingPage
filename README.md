# DevShuora School ERP Landing Page

Single-page corporate landing page built with HTML, Tailwind CSS v4 CLI and vanilla JavaScript. No React or frontend framework is used.

## Requirements
- Node.js 20+ recommended
- npm

## Install
```bash
npm install
```

## Development
```bash
npm run dev
```
Keep the Tailwind watcher running while editing. Open `index.html` using VS Code Live Server or another local static server.

## Production CSS
```bash
npm run build
```
The compiled CSS is written to `assets/css/output.css`.

## Structure
```text
devshuora-school-erp-landing/
├── index.html
├── package.json
├── README.md
├── src/input.css
├── assets/css/output.css
├── assets/images/
└── js/main.js
```
